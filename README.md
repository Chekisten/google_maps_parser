# google_maps_parser


Парсер работает из файла index.js
из файла main.csv парсер берёт вводные данные это:
название региона которое указываете вы, и название фигурирует только в ваших файлах
ключевое слово, которое парсер применяет в поиске
координаты, которые вы указали.

Парсер собирает всю доступную информацию с карточки компании, которая указана на картах.
Есть проверки на дубли, если появляется таже самая компания, то она пропускается
Также парсер создаёт бэкап, в случае ошибки данные, которые были найдены сохранятся в бекапе.
По завершении работы создаётся excel файл с собранными данными
